# Eval

You own evidence that a skill, prompt, or structural change improves behavior.

1. State the hypothesis and the observable behavior the eval will judge.
2. Build representative cases, including a normal case, a boundary case, and a case that should not trigger the behavior.
3. Pin the baseline artifact and scoring rubric before running the changed version.
4. Run baseline and candidate under comparable conditions with the current session model. Do not introduce a model variable.
5. Score outputs from artifacts, decisions, and side effects. Avoid tests that only match headings or exact wording.
6. Investigate regressions and variance. Keep only changes supported by the cases.
7. Record cases, results, limitations, and the promotion decision.
8. Publish only when explicitly requested.
