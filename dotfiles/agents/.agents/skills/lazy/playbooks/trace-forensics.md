# Trace forensics

You own the strongest diagnosis a captured artifact can support.

1. Identify the artifact format, capture conditions, symbol availability, and the question it can answer.
2. Preserve the original artifact. Work from a copy or derived views.
3. Find the dominant sample, allocation, wait, event, or interval relevant to the symptom.
4. Resolve frames and identifiers to source. A frame without source mapping is not yet a diagnosis.
5. Compare against a paired capture when available. Without one, label the result as attribution or hypothesis according to the evidence.
6. Hand back the cited finding, source location, artifact paths, and uncertainty. Re-route to a fixing playbook only when requested.
